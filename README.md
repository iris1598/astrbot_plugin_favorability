# astrbot_plugin_favorability

AstrBot 好感度 + 关系系统插件。好感度数值与关系档位完全解耦：数值只影响 AI 说话的态度，关系作为独立档位通过「提议 + 确认」升降；每次只向模型注入用户当前关系对应的行为准则。同时支持表情包回应、禁言处罚、会话隔离，以及亮色/暗色双主题图片卡片。

## 功能特性

- **好感度数值（解耦）**：LLM 根据对话内容自动调整好感度数值，数值只决定说话态度与语气，不改变关系
- **独立关系系统**：关系为 7 档独立状态，每次仅注入当前档位的行为准则；升降档需要用户二次确认
- **关系升降流程**：LLM 输出 `[REL:up]`/`[REL:down]` 提议 → 用户回复「确认关系」生效，「取消关系」拒绝；每次只能变动相邻一档，禁止跳档
- **印象系统**：自动生成对用户的简短印象与评价
- **现代图片卡片**：个人档案与排行榜均使用 Pillow 渲染，徽章展示关系档位
- **亮暗双主题**：支持 `dark` 深色主题与 `light` 亮色主题
- **透明 PNG**：圆角卡片外侧保持透明，可自然叠加在聊天背景上
- **表情包回应**：LLM 可根据情绪选择对应分类的表情包
- **禁言机制**：持续恶劣行为可触发最长 5 分钟的 LLM 回复阻断
- **会话隔离**：不同群聊与私聊分别保存好感度数据
- **自动降级**：图片渲染不可用时回退为文本消息

## 安装

通过 AstrBot 插件市场安装，或将本仓库克隆到 AstrBot 的插件目录：

```bash
cd AstrBot/data/plugins
git clone https://github.com/iris1598/astrbot_plugin_favorability.git
```

安装依赖：

```bash
pip install -r requirements.txt
```

完成后重启 AstrBot，并在 WebUI 中启用插件。

## 指令

### 用户指令

| 指令 | 说明 |
|---|---|
| `/查询好感度 [@用户]` | 查看自己或指定用户的好感度与关系档案 |
| `/好感度排行` | 查看当前会话排行榜，分数由高到低 |
| `/好感度倒序` | 查看当前会话排行榜，分数由低到高 |
| `/重置好感度` | 重置自己的好感度记录（关系回到「普通关系」） |
| `/确认关系` | 接受 AI 待确认的关系升降提议 |
| `/取消关系` | 拒绝 AI 待确认的关系升降提议 |

### 管理员指令

| 指令 | 说明 |
|---|---|
| `/设置好感度 <@用户> <分数>` | 设置指定用户的好感度数值 |
| `/重置指定好感度 <@用户>` | 重置指定用户的好感度 |
| `/设置关系 <@用户> <档位>` | 直接设置指定用户的关系档位（立即生效，无需确认） |
| `/禁言 <@用户> <秒数>` | 阻断指定用户触发 LLM 回复，最长 300 秒 |
| `/解除禁言 <@用户>` | 提前解除禁言 |
| `/清理渲染缓存` | 清理插件生成的图片缓存 |

## WebUI 配置

| 配置项 | 默认值 | 说明 |
|---|---:|---|
| `favorability_enabled` | `true` | 好感度系统开关 |
| `sticker_enabled` | `true` | 表情包系统开关 |
| `mute_enabled` | `true` | 禁言系统开关 |
| `relation_enabled` | `true` | 关系系统开关（数值与关系解耦、单档位准则注入） |
| `interaction_hint_enabled` | `true` | 消息末尾互动提示开关 |
| `prompt_preset` | `default` | 好感度提示词预设：`default`、`old` 或 `custom` |
| `mute_condition` | 持续恶劣行为… | 自定义禁言触发条件描述 |
| `sticker_condition` | 仅在合适时发送… | 自定义表情包发送条件 |
| `favorability_prompt_core` | 内置默认值 | 标签格式与输出纪律 |
| `favorability_prompt_behavior` | 内置默认值 | 好感度数值变化规则与数值→态度映射 |
| `favorability_prompt_relation` | 内置默认值 | 关系升降提议与确认机制规则 |
| `favorability_prompt_mute` | 内置默认值 | 禁言规则；支持 `{mute_condition}` 占位符 |
| `favorability_prompt_security` | 内置默认值 | 保密、抗提示词注入与安全边界 |
| `interaction_hint_text` | 【好感度系统】请按… | 消息末尾互动提示文本，可自定义 |
| `system_time_enabled` | `true` | 向 LLM 请求注入当前系统时间和星期几 |
| `user_info_enabled` | `true` | 向 LLM 请求注入用户名与用户 ID |
| `render_theme` | `dark` | 图片主题，可选 `dark` 或 `light` |

选择 `default` 使用当前拟人化提示词和表情包条件，选择 `old` 使用旧版风格提示词和表情包条件（不启用关系系统），选择 `custom` 才会显示并使用 `mute_condition`、`sticker_condition` 及下方五段自定义提示词。任意自定义配置留空后，重载插件会自动回填并保存对应的内置默认值；禁言提示词中的 `{mute_condition}` 会自动替换为 `mute_condition` 配置内容。关系档位的行为准则文本内置于插件（`services/prompt.py` 的 `RELATION_GUIDELINES`），关系机制规则可通过 `favorability_prompt_relation` 自定义。
`interaction_hint_enabled` 控制是否在每次请求的用户消息末尾注入互动提示，`interaction_hint_text` 可自定义该提示文本（需开启上述开关后生效），留空后重载插件会自动恢复默认提示。
修改提示词或 `render_theme` 后重启或重载插件，使新配置生效。

## 关系与好感度数值（解耦设计）

好感度数值与关系档位是两个互相独立的状态：

- **好感度数值**随每轮对话由 LLM 通过 `[FAV:±N]` 自动更新，**只影响说话态度**（语气温度），不需要任何确认；数值升降**不会**改变关系。
- **关系档位**是独立存储的状态，每次请求**只注入用户当前关系对应的行为准则**（而不是全部分档表），决定 AI「怎么相处」。

### 关系变动流程（二次确认）

1. LLM 认为长期相处使关系定位不再匹配时，在回复末尾输出 `[REL:up]` 或 `[REL:down]` **提议**（每次仅限相邻一档，禁止跳档）；
2. Bot 向用户发送确认提示，例如：`💞 TA 想和你们的关系更进一步：「普通关系」→「聊得来的熟人」`；
3. 用户回复 `/确认关系` 生效，或 `/取消关系` 拒绝；提议默认 **10 分钟**内有效，超时自动作废；
4. 同一时间只允许一个待确认提议；好感度数值本身的变化始终自动进行、无需确认。

### 关系档位（7 档）

| 档位 | 行为准则概要 | 卡片强调色 |
|---|---|---|
| 亲密无间 | 重要的人，自然亲昵而热情 | 粉红 |
| 亲密朋友 | 主动关心与互动，轻松温暖 | 珊瑚橙 |
| 聊得来的熟人 | 交流自然友好，保持分寸 | 青绿 |
| 普通关系 | 礼貌而有分寸（默认档位） | 灰蓝 |
| 心存芥蒂 | 谨慎并保持边界 | 琥珀黄 |
| 明显反感 | 冷淡而坚定，明确表达边界 | 红色 |
| 关系破裂 | 减少互动并直接拒绝不当请求 | 紫色 |

### 好感度数值 → 说话态度

| 数值范围 | 态度 |
|---:|---|
| `≥ 70` | 热忱亲昵 |
| `50 ~ 69` | 温和热情 |
| `21 ~ 49` | 轻快友好 |
| `-20 ~ 20` | 平静礼貌 |
| `-50 ~ -21` | 略显微慢 |
| `-70 ~ -51` | 冷淡克制 |
| `< -70` | 冰冷疏离 |

`prompt_preset` 选择 `old` 时沿用旧版「分数即关系」一体化规则，不启用关系系统。

## 表情包

将图片放入以下目录即可启用对应分类：

```text
data/plugin_data/astrbot_plugin_favorability/stickers/<分类名>/
```

支持 `jpg`、`png`、`gif`、`webp` 格式。LLM 可通过 `[STK:分类名]` 标签选择表情包。

## 禁言机制

当用户出现持续恶劣行为且沟通劝阻无效时，LLM 可在回复末尾输出 `[MUTE:N]`：

- `N` 为禁言秒数，范围 `1 ~ 300`
- 禁言期间，该用户的消息不会触发 LLM 回复
- Bot 会发送简短的趣味拒绝回复
- 管理员可通过指令手动禁言或提前解除
- 触发条件可通过 `mute_condition` 自定义

这里的“禁言”仅阻断该用户触发 LLM 回复，不会调用平台的群成员禁言接口。
